# Mod Porter website

The public website for Mod Porter: https://fifik-art.github.io/

Port Minecraft mods between Fabric, NeoForge and Forge. The porting itself runs in a separate private repository,
reached through a small backend (`config.json`). Questions, takedown and privacy requests: open an issue here.

- `donate.json`: donation links shown in the Support window
- `fonts/`, `vendor/`: self-hosted font (OFL) and JSZip (MIT), so the site loads nothing from third parties
